# Prompt File Format

Every prompt generated by SkillMall's Prompt Engine follows this format: YAML frontmatter followed by the self-contained prompt body.

## Frontmatter

```yaml
---
framework: Chain of Thought, Structured Output
original_framework: Chain of Thought, Structured Output
skill: blue-ocean-strategy
tool: strategy-canvas
type: tool-specific
produces: ["strategy-canvas-current.md", "strategy-canvas-proposed.md"]
when_to_use: "Use when you need to visualize the current competitive landscape before designing a new strategic position"
complexity: thorough
generated_by: prompt-engine
---
```

### Fields

| Field | Description |
|---|---|
| `framework` | Selected PE framework(s) — may differ from `original_framework` if user overrode |
| `original_framework` | Framework(s) selected by the algorithm — never overwritten |
| `skill` | Skill slug |
| `tool` | Tool slug (or `"meta"` for meta prompts) |
| `type` | `tool-specific` \| `category` \| `meta` |
| `produces` | Expected output filenames |
| `when_to_use` | One sentence — when this prompt outperforms others for this skill |
| `complexity` | `quick` \| `thorough` \| `exhaustive` |
| `generated_by` | Always `prompt-engine` for generated prompts |

### Complexity Assignment

| Complexity | Assigned when |
|---|---|
| `exhaustive` | Meta comprehensive analysis, meta cross-category synthesis |
| `quick` | Meta quick assessment, simple tool prompts (< 3 inputs and < 3 outputs) |
| `thorough` | All other meta prompts, category prompts, complex tool prompts |

## Prompt Body

The body is completely self-contained. Every tool structure (table, matrix, grid, validation checklist) is embedded inline as markdown. No references to external template files or resources.

**A prompt passes quality if:**
- First sentence is imperative: starts with `Produce`, `Analyze`, `Generate`, `Create`, `Evaluate`, or equivalent
- The artifact structure is embedded inline (not referenced as a file path)
- Validation rules are explicitly listed
- A completion checklist specifies what a valid output contains

## Prompt Count Formula

For a domain with N tools, C distinct categories, and M selected meta types:

```
total = N + C + M
```

Blue Ocean Strategy (21 tools, 3 categories, 5 meta): `21 + 3 + 5 = 29` prompts. Plus 1 cross-category synthesis = 30 total.


## Self-Contained Requirement

Every prompt file must be completely self-contained. When a user pastes the prompt body into any AI tool, it must contain everything needed to produce the artifact:

- The full artifact structure (table, grid, matrix) is embedded inline as markdown
- No references to external files
- All validation rules listed explicitly
- Completion checklist specifies what a valid output contains

## Quality Checks (Prompt Optimizer)

Before being written to disk, each prompt passes through the Prompt Optimizer, which audits 4 dimensions:

| Dimension | What it checks |
|---|---|
| Token efficiency | Words removable without changing output |
| Intent completeness | All 9 dimensions present (task, input, output, constraints, context, audience, memory, success criteria, examples) |
| Output clarity | Deliverable named, structured, ordered |
| Trigger sharpness | First sentence is imperative and unambiguous |

## Prompt Naming Convention

| Prompt type | File naming |
|---|---|
| Tool-specific | tool-<tool-slug>.md |
| Category | category-<category-slug>.md |
| Meta (standard) | meta-comprehensive-analysis.md, meta-quick-assessment.md, etc. |
| Meta (synthesis) | meta-cross-category-synthesis.md |

## Framework Override

To regenerate a prompt with a different framework via CLI:

```bash
npx skill-mall regen-prompt blue-ocean-strategy tool-strategy-canvas.md --framework "Tree of Thoughts"
```

This updates `framework` in frontmatter but preserves `original_framework`.
