# Technical Documentation Starter

A starter skill for writing technical documentation using the Divio documentation system. The four-quadrant model (tutorials, how-to guides, reference, explanation) produces docs that serve each type of reader need clearly.

## What's included

- Divio four-quadrant model: tutorials, how-to guides, reference, explanation
- Decision guide: which type to write for which reader need
- Templates for tutorials and how-to guides
- Team-customizable product name and audience

## Fill-in markers

### [FILL-IN: github-username]
Your GitHub username for the author field.

### [FILL-IN: product-name]
The product or system being documented. Examples:
- `SkillMall CLI`
- `Internal API Gateway`
- `The authentication service`

### [FILL-IN: primary-audience]
Who reads this documentation. Examples:
- `Developers integrating the REST API for the first time`
- `DevOps engineers deploying the service on Kubernetes`
- `Data analysts using the reporting dashboard`
