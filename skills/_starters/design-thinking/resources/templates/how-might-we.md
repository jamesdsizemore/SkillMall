## Stage 1 — Reframe the PoV into HMW Questions

Take the PoV statement and generate How Might We questions. Rules:
- Each HMW should be broad enough to allow creative responses
- Each HMW should be narrow enough to give direction
- Do not evaluate questions yet — generate first
- Aim for 20 questions minimum before filtering

**HMW questions:**

1. How might we [need from PoV]?
2. How might we make [part of the problem] easier for [user]?
3. How might we remove [identified obstacle] entirely?
4. How might we help [user] to [goal] without [constraint]?
5. How might we use [observed workaround] as the actual solution?
6. How might we flip [pain] into a feature?
7. How might we [action] before [problem] occurs?
8. How might we give [user] more [resource: time / information / confidence]?
9. How might we make [frustrating step] feel like [positive emotion]?
10. How might we help [user] accomplish [goal] in under [time/steps]?
