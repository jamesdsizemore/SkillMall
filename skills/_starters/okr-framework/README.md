# OKR Framework Starter

A starter skill for planning and tracking OKRs (Objectives and Key Results) using the method from John Doerr's "Measure What Matters" and Google's internal practice.

## What's included

- OKR formula: aspirational Objective + measurable Key Results
- Grading methodology with 70% success baseline
- Quarterly rhythm: set → check-in → grade → retrospect
- Quarterly OKR plan template
- OKR review meeting agenda template
- Team-customizable cycle and grading scale
