# API Documentation Starter

A starter skill for documenting REST APIs. Covers every endpoint, request/response shapes, error codes, authentication flows, and curl examples that callers can use immediately.

## What's included

- Endpoint documentation structure (method, auth, params, response, errors, examples)
- API overview page template (base URL, auth, rate limits, versioning)
- Single endpoint documentation template
- Team-customizable base URL and auth method

## Fill-in markers

### [FILL-IN: github-username]
Your GitHub username for the author field.

### [FILL-IN: api-base-url]
Your API's base URL. Examples:
- `https://api.yourproduct.com/v1`
- `https://yourproduct.com/api`
- `http://localhost:3000/api` (for local development docs)

### [FILL-IN: auth-method]
Your API's authentication method. Examples:
- `Bearer token in Authorization header: Authorization: Bearer <token>`
- `API key in X-API-Key header: X-API-Key: your-api-key`
- `Session cookie: automatically set after POST /auth/login`
