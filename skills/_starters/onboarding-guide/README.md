# Team Onboarding Guide Starter

A structured onboarding guide skill built on Shape Up's philosophy: new hires ship something real in week one. Includes a day-one setup checklist and a 30-60-90 day plan template.

## What's included

- SKILL.md with methodology drawn from [Shape Up by Basecamp](https://basecamp.com/shapeup)
- `day-one-checklist.md` — ordered setup checklist covering accounts, tools, meetings, and the first small task
- `30-60-90-plan.md` — structured plan template with goals, deliverables, key relationships, and success criteria per period
- Fill-in markers for team name, tools list, and the designated first task

## Fill-in markers

### [FILL-IN: github-username]
Your GitHub username for the `author` field in SKILL.md frontmatter.

### [FILL-IN: team-name]
The name of the team this guide is for, e.g. "Platform Engineering" or "Growth". Appears in the tools list header and throughout the guide.

### [FILL-IN: tools-list]
The complete list of tools new team members need access to, in the order they should be set up. Example: "GitHub org, Slack, Linear, Figma, AWS console (read-only)."

### [FILL-IN: first-task]
A concrete, real task completable by end of week one. Example: "Merge a PR that fixes a documentation typo in the API reference." Must touch production code or docs, not a sandbox.
