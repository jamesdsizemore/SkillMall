# Stakeholder Communication Starter

A starter skill for writing stakeholder status updates and project communications based on PMBOK communication planning principles. Produces updates that busy executives can scan in 30 seconds.

## What's included

- Bottom-line-up-front structure
- RAG status framework (Red/Amber/Green)
- Weekly status report template
- Executive summary template
- Team-customizable stakeholder list and project name

## Fill-in markers

### [FILL-IN: github-username]
Your GitHub username for the author field.

### [FILL-IN: stakeholder-list]
Your stakeholders and their communication preferences. Example:
```
- CTO: weekly written summary (Friday 5pm), Slack DM for blockers
- VP Engineering: weekly status email (copy CTO)
- Finance: monthly metrics report by 1st of month
- Product: daily Slack standup (no formal report)
```

### [FILL-IN: project-name]
The project being communicated about (e.g., "Platform Auth Migration", "Q2 API Redesign").

## Source

Based on [Project Management Institute PMBOK Guide — Communications Management](https://www.pmi.org/pmbok-guide-standards).
