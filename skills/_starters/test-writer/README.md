# Test Writer Starter

A starter skill for writing unit and integration tests using the AAA (Arrange, Act, Assert) pattern. Based on Martin Fowler's testing principles and the testing pyramid.

## What's included

- Testing pyramid reference: unit → integration → E2E
- AAA pattern with examples
- Test naming conventions (behavior-oriented)
- Test isolation rules
- Templates for unit tests and integration tests
- Team-customizable framework and coverage threshold
