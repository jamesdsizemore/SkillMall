# Sprint Planning Starter

A starter skill for running effective Scrum sprint planning sessions based on the Scrum.org Scrum Guide. Produces a Sprint Goal, a committed sprint backlog, and a task breakdown with clear ownership.

## What's included

- Two-part sprint planning structure (WHAT and HOW)
- Sprint goal writing guide
- Capacity planning formula
- Sprint planning agenda template
- Sprint goal statement template
- Team-customizable sprint length, velocity, and Definition of Done

## Fill-in markers

### [FILL-IN: github-username]
Your GitHub username for the author field.

### [FILL-IN: sprint-length]
Your sprint duration. Examples:
- `2 weeks (10 working days)`
- `1 week (5 working days)`

### [FILL-IN: team-velocity]
Your team's average velocity. Examples:
- `32 story points per 2-week sprint (6-sprint rolling average)`
- `We use t-shirt sizes, target 8-10 medium stories per sprint`

### [FILL-IN: definition-of-done]
Your team's DoD. Examples:
- `Code reviewed, all tests passing, deployed to staging, PO accepted`
- `Code reviewed, unit tests added, linter passes, merged to main`
