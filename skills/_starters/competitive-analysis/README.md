# Competitive Analysis Starter

A starter skill for applying Porter's Five Forces framework to assess industry attractiveness and identify structural competitive pressures. Based on Michael Porter's original 1979 Harvard Business Review framework.

## What's included

- Porter's Five Forces: threats, supplier/buyer power, rivalry, substitutes
- Industry attractiveness scoring methodology
- Five Forces analysis worksheet
- Competitive positioning matrix
- Team-customizable industry name and time horizon
