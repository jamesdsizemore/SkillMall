# PR Description Writer Starter

A starter skill for writing clear, complete pull request descriptions that answer reviewer questions before they're asked.

## What's included

- WHAT / WHY / HOW structure for every PR
- Breaking-change handling guidance
- Templates for standard PRs and breaking-change PRs
- Team-customizable checklist and PR template reference

## Fill-in markers

### [FILL-IN: github-username]
Your GitHub username for the author field.

### [FILL-IN: pr-template-url]
URL to your team's PR template file. Example: `https://github.com/your-org/your-repo/blob/main/.github/PULL_REQUEST_TEMPLATE.md`

### [FILL-IN: review-checklist-items]
Your team's standard PR checklist items. Examples:
- Tests added or updated
- Documentation updated
- No secrets committed
- DB migration included (if schema changed)
