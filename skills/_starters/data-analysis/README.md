# Data Analysis Starter

A structured data analysis workflow built on Hadley Wickham's tidy data principles (2014). Covers the full pipeline from question definition through communication, with explicit reproducibility requirements.

## What's included

- SKILL.md with methodology drawn from [Tidy Data (Wickham 2014)](https://vita.had.co.nz/papers/tidy-data.html)
- `tidy-data-checklist.md` — validation checklist for confirming a dataset meets tidy data standards before any EDA or modeling
- Fill-in markers for data source and analysis tool

## Fill-in markers

### [FILL-IN: github-username]

### [FILL-IN: data-source]

### [FILL-IN: analysis-tool]
