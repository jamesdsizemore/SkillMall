# Blue Ocean Strategy Starter

A starter skill for applying the Blue Ocean Strategy framework: Four Actions Framework (ERRC grid) and Strategy Canvas for identifying uncontested market space.

## What's included

- Four Actions Framework: Eliminate, Reduce, Raise, Create
- Strategy Canvas plotting guide
- Non-customer analysis (three tiers)
- ERRC grid template
- Strategy canvas table template
- Team-customizable industry and competitor names
