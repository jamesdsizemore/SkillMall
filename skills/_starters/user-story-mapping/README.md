# User Story Mapping Starter

A starter skill for building User Story Maps using Jeff Patton's method. Creates a shared visual representation of the user journey that prevents feature-factory syndrome by keeping the narrative visible.

## What's included

- Three-layer map: backbone activities → tasks → stories
- Walking skeleton concept (minimum viable end-to-end journey)
- Release slicing: horizontal cuts across the backbone
- Story map template
- Individual user story card template
- Team-customizable persona names and release naming

## Fill-in markers

### [FILL-IN: github-username]
Your GitHub username for the author field.

### [FILL-IN: persona-names]
Your product's primary user personas. Examples:
- `Admin, End User, Support Agent`
- `Developer (integrating), End User (browsing), Author (publishing)`
- `Buyer, Seller, Platform Admin`

### [FILL-IN: release-names]
Your release naming convention. Examples:
- `Walking Skeleton, v1.0, v1.1, v2.0`
- `MVP, Phase 2, Phase 3`
- `Sprint 1, Sprint 2, Sprint 3`
